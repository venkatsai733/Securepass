# 🔐 SecurePass – Password Generator

SecurePass is a Python-based password security application designed to help users create strong and secure passwords.

The application provides a simple and user-friendly interface where users can create an account and receive a strong password suggestion. Users can either use the suggested password or close the suggestion and create their own password.

## ✨ Features

- 🔐 Strong password generation
- 🎲 Random password creation
- 👤 User-friendly account creation interface
- 💡 Automatic password suggestion during signup
- ✕ Option to close the suggestion and create your own password
- 📊 Password strength indicator
- 👁 Show/Hide password
- 🔑 Password confirmation
- 🖥️ Clean and modern desktop interface
- ⚡ Built completely using Python

## 🛠️ Technologies Used

- Python
- Tkinter
- `secrets` module
- `string` module
- Regular Expressions (`re`)
